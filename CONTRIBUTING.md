# Contributing to Thrustmaster FGT Linux Driver

First off, thanks for taking the time to contribute!

## How Can I Help?

### Reporting Bugs

* Check the [Issues](https://github.com/thaubert/steering-wheel-driver/issues) page to see if the bug has already been reported.
* If not, create a new issue. Include details about your Linux distribution, kernel version, and exactly what is happening.

### Suggesting Enhancements

* Open an issue to discuss your idea.
* If you can implement it, pull requests are welcome!

### Pull Requests

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Ensure your code follows the project's style (run a linter if possible).
4. Submit a pull request.

## Development Setup

1. Clone your fork.
2. Install dependencies: `pip install -e .`
3. Run the driver in debug mode: `python3 src/fgt_remapper.py --debug`

## Code of Conduct

Please be respectful and professional in all interactions.
